# JADEX ACADEMY

**Master Coding, Design & Tech at Your Own Pace** — An interactive online learning platform and student progress dashboard built from scratch with HTML, CSS, and JavaScript.

## About the Project
Jadex Academy is a modern EdTech platform featuring curated learning categories, project-based bootcamps, mentor profiles, and a live student dashboard that tracks lesson completion in real time.

## Design & Aesthetic
* **Color Palette:** Deep Forest Sage, Soft Cream, and Crisp White surfaces accented with Warm Amber Gold and Terracotta highlights.
* **Typography:** Pairs *Fraunces* editorial serif headings with clean *Plus Jakarta Sans* interface copy.

## Features
* **Course Catalog & Categories:** Structured bootcamps across Web Development, Python & Django, UI/UX Branding, and PHP.
* **Live Student Dashboard:** Enrolling in any course adds it to your personal workspace with a live progress bar, **+ Complete Lesson (+1)** tracker, and automatic overall mastery percentage calculation.
* **Instructor Profiles:** Spotlight cards highlighting mentor specialties and experience.

## Built With
* **HTML5** — Semantic EdTech layout
* **CSS3** — Custom variables, CSS Grid, Flexbox, and smooth hover transitions
* **Vanilla JavaScript** — Real-time course enrollment state, progress bar math, and dynamic dashboard rendering
